# Bundled background photos

Place JPG, JPEG, PNG, or WebP images directly in this folder, then rebuild/package the app.
They appear in both background menus for every user, offline. File names become display
names (for example, `Ararat at dusk.jpg`). Keep file names stable between releases.

These choices do not override a user's selected background. The built-in Quiet blue
remains the initial selection. Photos imported through Settings remain personal.

Use images you have permission to distribute. Keep any credits or license files here;
they will be included in the packaged app. Prefer screen-sized images under 20 MB.
